# Руководство пользователя - Бот-пиццерия

## Добро пожаловать в бот-пиццерию! 🍕

Этот бот поможет вам заказать вкусную пиццу и напитки прямо в Telegram. В этом руководстве вы найдете всю необходимую информацию для работы с ботом.

## Начало работы

### Запуск бота
1. Найдите бота в Telegram по имени или ссылке
2. Нажмите `/start` для начала работы
3. Выберите нужное действие из главного меню

### Главное меню
После команды `/start` вы увидите главное меню с следующими опциями:
- 🍕 **Меню** - просмотр каталога товаров
- 🛒 **Корзина** - просмотр и управление корзиной
- ℹ️ **О нас** - информация о пиццерии
- 💳 **Варианты оплаты** - способы оплаты заказа
- 🚚 **Варианты доставки** - информация о доставке

## Как заказать пиццу

### Шаг 1: Просмотр меню
1. Нажмите кнопку **"Меню"** в главном меню
2. Выберите интересующую категорию товаров
3. Просматривайте товары, используя кнопки **"⬅️"** и **"➡️"** для навигации

### Шаг 2: Добавление в корзину
1. При просмотре товара нажмите **"Добавить в корзину"**
2. Товар будет добавлен в корзину с количеством 1
3. Для добавления еще одного экземпляра нажмите кнопку еще раз

### Шаг 3: Управление корзиной
1. Перейдите в **"Корзину"** из главного меню
2. Просмотрите добавленные товары
3. Используйте кнопки **"+"** и **"-"** для изменения количества
4. Нажмите **"❌"** для удаления товара из корзины
5. Посмотрите общую стоимость заказа

### Шаг 4: Оформление заказа
1. В корзине нажмите **"Заказать"**
2. Следуйте инструкциям для завершения заказа

> ⚠️ **Важно**: В текущей версии функция оформления заказа находится в разработке

## Навигация по меню

### Категории товаров
Товары разделены на категории для удобного поиска:
- 🍕 Пицца
- 🥤 Напитки
- 🍟 Закуски (если доступны)

### Постраничная навигация
- **⬅️ Назад** - предыдущий товар
- **➡️ Вперед** - следующий товар
- **🔙 Назад в меню** - возврат к выбору категорий

## Информационные разделы

### О нас
Содержит информацию о пиццерии, часы работы и контактные данные.

### Варианты оплаты
Описание доступных способов оплаты заказа.

### Варианты доставки
Информация о зонах доставки, стоимости и времени доставки.

## Команды бота

### Основные команды
- `/start` - Запуск бота и отображение главного меню
- `/menu` - Быстрый переход к каталогу товаров
- `/cart` - Быстрый переход к корзине
- `/about` - Информация о пиццерии
- `/payment` - Информация об оплате
- `/shipping` - Информация о доставке

## Советы по использованию

### Быстрая навигация
- Используйте команды для быстрого перехода к нужным разделам
- Кнопка **"🏠 Домой"** всегда возвращает в главное меню

### Управление корзиной
- Регулярно проверяйте корзину перед оформлением заказа
- Используйте кнопки **"+"** и **"-"** для точной настройки количества
- Помните, что корзина сохраняется между сессиями

### Выбор товаров
- Внимательно читайте описание товаров
- Обращайте внимание на цены
- Используйте изображения для лучшего понимания товара

## Решение проблем

### Бот не отвечает
1. Попробуйте написать `/start`
2. Проверьте интернет-соединение
3. Перезапустите чат с ботом

### Товары не загружаются
1. Попробуйте обновить меню командой `/menu`
2. Вернитесь в главное меню и повторите попытку

### Проблемы с корзиной
1. Попробуйте команду `/cart`
2. Проверьте, добавлены ли товары
3. При необходимости очистите корзину и начните заново

### Ошибки при заказе
1. Проверьте правильность заполнения всех данных
2. Убедитесь, что корзина не пуста
3. Попробуйте оформить заказ еще раз

## Обратная связь

Если у вас возникли вопросы или предложения по улучшению бота, обратитесь к администратору пиццерии через раздел **"О нас"**.

A: Свяжитесь с администратором пиццерии для изменения заказа.

A: Информация о времени доставки доступна в разделе "Варианты доставки".

**Q: Принимаете ли вы банковские карты?**
A: Информация о способах оплаты доступна в разделе "Варианты оплаты".

**Q: Есть ли минимальная сумма заказа?**
A: Информацию о минимальной сумме заказа уточняйте в разделе "О нас".

**Q: Можно ли заказать на определенное время?**
A: Обратитесь к администратору для уточнения возможности заказа на определенное время.
