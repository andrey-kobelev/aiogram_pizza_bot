# 📚 Документация проекта "Бот-пиццерия"

Добро пожаловать в центр документации проекта! Здесь вы найдете всю необходимую информацию для работы с ботом-пиццерией.

## 📖 Обзор проекта

**Бот-пиццерия** - это Telegram бот для заказа пиццы и напитков с полнофункциональной административной панелью. Проект написан на Python с использованием Aiogram3, SQLAlchemy и SQLite.

### 🚀 Основные возможности
- 🍕 Каталог товаров с категориями
- 🛒 Корзина покупок с управлением количеством
- 📱 Интуитивное меню навигации
- 👤 Автоматическая регистрация пользователей
- ⚙️ Административная панель для управления товарами
- 🖼️ Поддержка изображений товаров и баннеров
- 📄 Постраничная навигация (пагинация)

## 🚀 Быстрый старт

### Для пользователей
1. Найдите бота в Telegram
2. Отправьте команду `/start`
3. Следуйте инструкциям из [Руководства пользователя](USER_GUIDE.md)

### Для разработчиков
1. Склонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Настройте переменные окружения в `.env`
4. Изучите [Техническую документацию](TECHNICAL_DOCS.md)

### Для системных администраторов
1. Подготовьте сервер согласно требованиям
2. Следуйте [Руководству по развертыванию](DEPLOYMENT_GUIDE.md)
3. Настройте мониторинг и резервное копирование
